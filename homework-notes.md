Git для новичков — конспект
Что такое Git
Консольная утилита для отслеживания истории изменений файлов (чаще всего кода). Позволяет откатываться к старым версиям, сравнивать и сливать изменения.
Базовые понятия

Репозиторий — хранилище кода с историей изменений
Коммит — точка сохранения с уникальным hash и комментарием
Ветка — цепочка коммитов, у каждой своё название (основная обычно называется main или master)

Установка

Windows — скачать установщик с официального сайта
macOS — через brew install git или встроенный запрос установки Command Line Tools
Linux — sudo apt install git (Debian/Ubuntu) или sudo yum install git (CentOS)

Первоначальная настройка
bashgit config --global user.name "Имя"
git config --global user.email "почта@email.com"
Создание репозитория
bashcd путь/к/проекту
git init
git add .
git commit -m "комментарий"
Когда делать коммиты
Не после каждой мелкой правки, а по смысловым блокам: новый функционал, исправление багов, конец рабочего дня и т.д. — так история остаётся читаемой.
Графические инструменты
Вместо консоли можно использовать GitHub Desktop, Sourcetree, GitKraken или встроенный Git-интерфейс в редакторах (например, VS Code).
Публикация на GitHub через VS Code

Создать папку проекта, открыть в VS Code
Написать код, сохранить файл
Во вкладке Git нажать "Опубликовать на GitHub" → выбрать публичный репозиторий
Подтвердить вход в GitHub-аккаунт
Дальнейшие изменения: закоммитить (добавить файл, написать комментарий, создать коммит) → отправить (push) в GitHub

Команды для дальнейшего изучения
git help, git clone, git status, git branch, git checkout, git merge, git remote, git fetch, git push, git pull
